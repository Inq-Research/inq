# Test Alpha

A small publishing workspace for live GitHub acquisition tests, rooted below
the repository's own workspace. Start with the [introduction](modules/alpha-intro/inq.md).

The introduction links to the [reference](modules/alpha-reference/inq.md), which
links to the [leaf](modules/alpha-leaf/inq.md). The
[unlinked module](modules/alpha-unlinked/inq.md) is discoverable in this workspace
but belongs to none of their dependency closures.
