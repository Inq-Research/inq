# Welcome to Beta

Beta's [local leaf](../../alpha-leaf/inq.md) belongs to this publishing workspace.
It shares its canonical name with Alpha's leaf, but is a different module.

The [Alpha welcome note](../../../_inq/alpha-source/notes/welcome.md) comes from
the exact external module bound to the publisher's `alpha-source` alias. That
note leads through Alpha's reference to Alpha's own leaf.

The [Alpha measurements](../../../_inq/alpha-source/data/measurements.csv) are
ambient data owned by the same external module. Linking that resource also
resolves through the publisher's exact binding.
